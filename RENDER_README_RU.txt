Вход: ADMIN_USERNAME / ADMIN_PASSWORD.

- роли содержат только права;
- редактирование профиля администратора;
- просмотр чужих профилей;
- журнал изменений в каждом профиле;
- общий аудит;
- Discord nickname/avatar через мост бота;
- улучшенный статус и статистика;
- права ролей редактируются отдельно;
- управление ролями;
- пароль можно менять при редактировании профиля.
