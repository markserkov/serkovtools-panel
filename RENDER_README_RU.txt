SerkovTools Panel v22

Что добавлено:
- Отдельный журнал действий администрации: кто, что, когда и с какого IP сделал.
- Отдельный журнал входов: успешные входы, выходы и неудачные попытки входа.
- Неудачная попытка входа сохраняет введённый логин, IP, User-Agent, маршрут и результат даже без авторизации.
- IP берётся через Express req.ip с trust proxy для Render.
- Сессии переведены с MemoryStore на SQLiteStore (sessions.sqlite), cookie rolling на 7 дней.
- Страницы теперь имеют постоянные адреса: /admins, /roles, /logs, /server и /profile<ID>.
- При обновлении страницы остаётся тот же раздел.
- При открытии профиля URL становится /profile<ID>; при обновлении профиль открывается снова.
- Существующая база panel.sqlite не заменяется.

Render:
1. Замените файлы панели файлами из этого архива.
2. Не удаляйте panel.sqlite, если он уже есть.
3. Сделайте Deploy.
4. Новый файл sessions.sqlite создастся автоматически.

Зависимость connect-sqlite3 добавлена в package.json. Render установит её через npm install.
